Esquema Funcional de Universilabs

ESTRUCTURA UNIVERSILABS
=======================

Institución (Seniorclick)
│
└─── Proyecto / Curso (Project)
     │   [Atributos: título, descripción, nivel, activo]
     │
     ├─── Inscripciones (Enrollment) <───> Usuarios (UserEntity)
     │    └─ Roles de Curso: [LEARNER, MENTOR, COLLABORATOR]
     │
     └─── JERARQUÍA DE CONTENIDO
          └─ Colección (CollectionEntity)
             └─ Tema (Topic)
                └─ Subtema (Subtopic)
                   └─ Página (Page)
                      ├─ Atributos: [Título, Contenido, Autor]
                      ├─ Recursos (Resource) ──► [Título, Tipo, URL, Orden]
                      ├─ Comentarios (Comment)
                      ├─ Contribuciones (Contribution)
                      └─ Progreso (UserProgress)
                         └─ [Estado, Tiempo, Último Acceso, Motivación]

SEGURIDAD Y PERFILES
====================

Usuarios (UserEntity)
│   [Seguridad: email, username, password, activo, verificado]
│
├─── Perfil (UserProfile) ───► (Relación 1:1)
│    └─ [Nombre, Apellido, Teléfono, Avatar]
│
├─── Roles Globales (RoleEntity)
│    └─ [ADMIN, USER, INSTRUCTOR]
│
└─── Permisos (PermissionEntity)
     └─ [READ_USERS, WRITE_PROJECTS, etc.]
